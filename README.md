# Тренажер іспиту FIFA Football Agent (PWA)

## Публікація на GitHub Pages
1. Створи новий репозиторій (наприклад, `fifa-agent`) і завантаж у корінь усі файли з цього архіву:
   `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` (усі файли лежать в корені, без папок).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 хвилини сайт буде доступний за адресою `https://<логін>.github.io/fifa-agent/`.

## Встановлення на iPhone
Відкрий адресу в **Safari** → кнопка «Поділитися» → **«На екран “Додому”»** → «Додати».

## Встановлення на Android
Відкрий адресу в **Chrome** → меню ⋮ → **«Встановити додаток»** (або «Додати на головний екран»).

Після першого відкриття тренажер працює й без інтернету. Історія спроб і список помилок зберігаються на телефоні.

## Оновлення
Заміни `index.html` у репозиторії новою версією. Якщо зміниш інші файли, збільш номер `CACHE` у `sw.js` (наприклад, `fifa-agent-v2`).
